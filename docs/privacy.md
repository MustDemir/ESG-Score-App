## Welche Daten verarbeiten wir?

### 1. Produktanfragen (Open Food Facts)
Beim Scannen eines Barcodes wird die EAN an die Open Food Facts API (`world.openfoodfacts.org`)
übertragen, um Produktinformationen abzurufen. Es werden keine personenbezogenen Daten mitgesendet.

### 2. Konto (optional)
Wer ein Konto anlegt, hinterlegt E-Mail-Adresse und (bei Apple Sign-In) eine Apple-ID-Relay-Adresse.
Speicherung erfolgt bei Supabase (EU-Region Frankfurt, Deutschland).

### 3. Scan-Verlauf
Gescannte Produkte und Präferenzen werden lokal sowie — bei aktivem Konto — in der Supabase-Datenbank
(EU) gespeichert. Verarbeitung ausschließlich zur Bereitstellung der App-Funktionen.

### 4. Telemetrie
Aktuell keine Tracking-SDKs. Crashlogs nur bei expliziter Opt-In-Zustimmung.
